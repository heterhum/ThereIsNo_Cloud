# Run locally

## Dependencies

- Docker Engine
- Docker Compose
- Node >= 18
- npm

## Installation instructions

Install npm depencies:
```bash
npm install
```

## Run

Run mongodb database with:
```bash
docker compose up -d --build
```

Then run the web server with:
```bash
npm start
```
